Factory Inventory Management System

src/api.js — single axios surface

Request lifecycle

What actually happens between a click on the filter bar and a redrawn chart. This is the one genuinely ordered sequence in the system.

  1. A user changes a control in FilterBar.vue, which writes to a ref declared outside the useFilters() export — so the value is a module singleton shared by every component that imports it.
  2. The active view calls getCurrentFilters(), which renames the UI's vocabulary to the API's: selectedLocation → warehouse, selectedPeriod → month.
  3. api.js builds a query string, omitting every filter still set to 'all'.
  4. axios issues a GET to port 8001; the browser's preflight passes because CORS is open to all origins.
  5. FastAPI matches the route and coerces each query param into Optional[str].
  6. apply_filters() narrows the in-memory list — warehouse matched exactly, category and status compared case-insensitively — then filter_by_month() applies either a YYYY-MM substring match or a quarter expansion via QUARTER_MAP.
  7. The Pydantic response_model validates every row and serializes the list to JSON. A field present in the data but missing from the model is silently dropped here.
  8. The view assigns the payload to a ref; computed properties derive totals, trends, and chart geometry; the inline SVG re-renders.

Operational characteristics

What this architecture buys, and what it defers. The README is explicit that this is a demo; these are the specific gaps behind that label.

Working well

  • Filter logic lives in one place per tier — useFilters and apply_filters
  • Pydantic guarantees response shape at the boundary
  • Zero-latency reads; no query planning or N+1 risk
  • Three-role subagent and skill config committed alongside the code

Deferred by design

  • No persistence — every write path is absent and restarts reset state
  • Filtering is O(n) per request in Python; fine at 250 rows
  • QUARTER_MAP is hardcoded to 2025 and needs editing each year
  • Quarter logic is duplicated in /api/reports/quarterly rather than reusing the map

Blocking production

  • No authentication — logout() raises a browser alert
  • allow_origins=["*"] with allow_credentials=True
  • Six client methods call routes that do not exist
  • No frontend test suite; backend covers three modules

Local topology

  • Vite dev server on :3000, no proxy — the client hardcodes the absolute API base URL
  • uvicorn on 0.0.0.0:8001, OpenAPI at /docs
  • scripts/start.sh installs deps if missing, then backgrounds both processes
